# Monitor-Rücknahme

Web-App zum Erfassen abgebauter Monitore per Asset-ID (Barcode-Foto, Galerie, Handscanner), mit Erweitert-Modus (Etage, Raum, Büro, Arbeitsplatz, Ersatzgerät) und Excel-Export. Läuft offline, Daten bleiben lokal im Browser.

Installation: Seite in Chrome öffnen → ⋮ → «Zum Startbildschirm hinzufügen» / «App installieren».
